# TrueNorth Dental — project notes

## Project conventions
- **Stack**: Node.js + Express 4 + EJS 3 + compression + serverless-http. No database, no CMS,
  no frontend framework, no runtime CDN. `sharp` is a devDependency (image pipeline only).
- **Content lives in `data/`**, never in templates. `data/site.js` is the single source of
  truth for NAP, hours, nav, socials, insurance, stats and footer — nothing business-specific
  is hard-coded in a view.
- **Content budget: 700–900 words per page.** Paragraphs 2–3 sentences (max 60 words), at most
  two `prose` blocks per page, 4–6 blocks total, FAQs 5–7 with 1–2 sentence answers. Enforced
  by `node scripts/wordcount.js`. The client explicitly rejected the original 2,000+ word pages
  as too long for mobile.
- **`CONTENT_SCHEMA.md` is the contract** for all content files (block types, field names,
  allowed icon names, business facts, image paths). Read it before editing any page.
- **Never set a `padding` shorthand on an element that also has `.container`.** A shorthand
  zeroes the horizontal padding and pushes hero copy flush to the screen edge. Use
  `padding-block`. This bit the hero and page-hero on every page — see `scripts/verify-ui.js`
  for the regression guard.
- **Mobile patterns that must stay:** tables stack into cards below 720px (they need the
  `data-label` attribute set in `blocks.ejs`); card grids become horizontal rows below 700px;
  touch targets are 44px; the sticky mobile action bar appears past the hero and hides at the
  page bottom.
- **Static requires only** in `data/services/index.js`, `data/pages/index.js`,
  `data/posts/index.js`. A dynamic `require('./' + slug)` cannot be resolved by esbuild and
  breaks the Netlify function on every request.
- **Icons**: inline SVG via `lib/icons.js`. Add new names there; never use an icon font.
- **Images**: WebP masters in `img/`, responsive variants + `img/manifest.json` generated by
  `npm run images`. `lib/img.js` reads the manifest at boot to build `srcset`. Never hardcode
  image widths in templates — use `imgTag(src, alt, { sizes })`.
- **CSS**: one stylesheet (`public/css/style.css`), brand colours as custom properties on
  `:root`. Breakpoints: 1300 / 1240 / 1200 / 1080 / 1060 (mobile nav takeover) / 860 / 760 / 480.
- **Scroll reveals**: `animation` + `.is-done` cleanup, never `transition`. Hidden state is
  gated behind `html.js`.
- **Never put `transform`, `filter` or `backdrop-filter` on `.site-header`** — it breaks the
  fixed mobile drawer. Nav overlay stays at `z-index: 99` (below the header's 100).

## Brand
- Palette: navy `#063B8C` (headings/primary), blue `#0878D9` (buttons/CTAs),
  teal `#08A8B8` (accents/icons), cyan `#DDF6F8`, soft blue `#EAF4FC`, white,
  dark slate `#172B4D` (body), light gray `#F5F8FA`.
- Font: Plus Jakarta Sans, self-hosted at `public/fonts/` (weights 400–800, latin subset).
- Voice: warm, plain-spoken, confident. No hype, no fear-based selling, no "best dentist" claims.

## Commands
```
npm start              # run the Express server on :3000
npm run images         # regenerate WebP masters, variants, favicons, og-image
npm run fonts          # re-download self-hosted fonts (one-off)
npm run verify:ui      # Playwright UI assertions + screenshots
node scripts/check-seo.js       # validate JSON-LD, footer credit, SEO tags
npm run prepare:netlify         # copy img/ → public/img/ for the Netlify publish dir
```

## Git
- Repo: https://github.com/kcwebdesignpros/truenorth.git (public), default branch `main`.
- Commit identity is set **repo-local** to `KC Web Design Pros <hello@kansascitywebdesignpros.com>`
  (there is no global git identity on this machine).
- Auth via Git Credential Manager (`credential.helper=manager`). `GIT_TERMINAL_PROMPT=0` is set
  machine-wide, so only the GCM browser flow works — never expect a terminal prompt.
- `.gitattributes` enforces LF; `core.autocrlf=false` locally.
- Never commit `public/img/` (build artefact), `img/raw/` (27 MB generator output) or
  `_screenshots/` — all gitignored.

## Deployment
- **Netlify** (primary target): `netlify.toml` publishes `public/`, routes everything to
  `netlify/functions/server.js` via `serverless-http`. `included_files` must list
  `views/** data/** lib/** img/** public/**`. Set `SITE_URL` env var.
- `netlify.toml` sets `NODE_ENV = "production"`, which makes `npm install` **skip
  devDependencies** — so there is deliberately **no `postinstall` script**. `sharp` is only
  needed by `npm run images` locally. All WebP masters, responsive variants, favicons and
  `img/manifest.json` are committed, so the Netlify build only has to copy `img/` → `public/img/`.
- **Vercel / VPS**: the server is host-agnostic (`lib/root.js` probes for the repo root;
  `app.listen` only runs when `require.main === module`).
- Before deploying, verify the bundle locally: bundle `netlify/functions/server.js` with
  esbuild, copy `views/ data/ lib/ img/manifest.json` beside it in a directory with **no**
  `node_modules` on the resolution path, assert `require.resolve('ejs')` throws, then invoke
  `handler()` with a synthetic event.
