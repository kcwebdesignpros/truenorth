# 2026-10-04 — TrueNorth Dental website build

## What was built
Complete multi-page marketing site for **TrueNorth Dental** (Kansas City, MO northland).
Stack: Node.js + Express + EJS, data-driven content, zero database, zero runtime CDN.

- **29 routes**: home, 6 service pages, 14 inner pages, 5 blog posts, blog index,
  HTML sitemap, search, 404, plus dynamic `sitemap.xml` and `robots.txt`.
- **Content**: every page is 2,000+ words of main content (verified by script).
- **Design**: implemented the supplied reference layout (dark image hero → overlapping
  3-card action bar → circular/split intro → 6 icon service cards) with the client palette
  (navy #063B8C, blue #0878D9, teal #08A8B8, cyan #DDF6F8, soft #EAF4FC, slate #172B4D).
- **Imagery**: 14 AI-generated photos → WebP masters + 55 responsive variants + `manifest.json`;
  favicons (16/32/48/180/192/512 + real `.ico`) and a 1200×630 `og-image.jpg`.
- **Fonts**: Plus Jakarta Sans self-hosted (latin subset, 72 KB total, 5 weights).
- **SEO**: LocalBusiness/Dentist, WebSite+SearchAction, Service+Offer, FAQPage,
  BreadcrumbList, BlogPosting, ItemList, HowTo, Physician, AggregateRating/Review.
- **Netlify**: `netlify.toml`, `netlify/functions/server.js` (serverless-http),
  `scripts/prepare-netlify.js` (copies `img/` → `public/img`).

## Key decisions
- **Generic block renderer** (`views/partials/blocks.ejs`) — 20 block types including
  data-driven ones (`services-grid`, `testimonials`, `team-grid`, `blog-grid`,
  `blog-preview`, `insurance-strip`, `offer`, `trust-bar`). Content files describe content
  only; adding a block type gives every page that capability.
- **Scroll reveal uses `animation`, not `transition`**, with an `.is-done` cleanup class so
  hover transforms survive. Hidden state gated behind `html.js`.
- **CSP with a per-request nonce** for the two inline scripts; `style-src` allows
  `'unsafe-inline'` because the reveal stagger uses inline `--d` custom properties.
- **Mobile drawer breakpoint raised to 1060px** and the mega-menu anchors to `.nav`
  (not the `<li>`) so a 620px panel can never be pushed off-screen.

## Bugs found and fixed (worth remembering)
1. **Dynamic `require` breaks the Netlify bundle.** `data/*/index.js` originally used
   `require('./' + slug)`. esbuild cannot resolve that, so the deployed function threw
   `Module not found in bundle: ./general-dentistry` on **every** request. Fixed by making
   all requires static. The local server never revealed this — only the bundled simulation did.
2. **Image variant pruning direction.** The "drop variants that aren't lighter" rule must
   compare against the previous *larger* size. Iterating smallest→largest and comparing to
   `lastBytes` deleted every variant except the smallest.
3. **Dark wordmark on dark backgrounds.** The logo's navy text vanished on the navy OG
   overlay and footer — both now place the logo on a white badge.
4. **Absolute preload URLs.** `preloadImage` used `absUrl()`, which pointed the preload at
   the production domain during local dev (double download). Must be a relative path.
5. **Google Fonts CSS subset parsing.** Comments precede the block they describe
   (`/* latin */ @font-face {...}`), so splitting on `@font-face` gives an off-by-one.
   Parse `/\/\*\s*([a-z0-9-]+)\s*\*\/\s*@font-face\s*\{([^}]*)\}/g` instead.

## Verification tooling (kept in repo)
- `scripts/verify-ui.js` — Playwright harness, 15 assertions (dropdown geometry, header
  overflow across 10 widths, drawer click-through, topbar height stability, reduced-motion
  fallback, horizontal scroll). All pass.
- Serverless simulation: esbuild bundle + `included_files` copy into a directory with no
  `node_modules` on the resolution path, asserting `require.resolve('ejs')` throws first.
